# bazis-test-utils 2.5.2

## Changes

- **The schedules of bazis-bg.** `apply_declarations()` and the fixture `bazis_declared`
  also apply the periodic tasks declared in the `schedules.py` modules (bazis-bg 2.6,
  `bazis.contrib.bg.declare`), as `migrate` does; an older bazis-bg without them is
  skipped.
