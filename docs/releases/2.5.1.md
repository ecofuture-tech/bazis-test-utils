# bazis-test-utils 2.5.1

## Fixes

- **The connections of the worker threads are closed.** The endpoints called by
  `get_api_client` run in worker threads, and a `TestClient` outside a `with` block starts
  new ones for every request. Each opened a database connection of its own that the core
  keeps for `CONN_MAX_AGE` (60 seconds) and closes only when it is obsolete, so it stayed
  open when its thread ended, until the garbage collector deleted it: a `ResourceWarning`
  of psycopg per request, and at the end of the session `DROP DATABASE` of the test
  database failed (`is being accessed by other users ... N other sessions`), which left
  it behind. The plugin records the connections that other threads than the one of the
  tests open, closes those of the ended threads when another one is opened (a test keeps
  about one session whatever the number of its requests), the others after each test and
  before the test database is destroyed. A thread that uses its connection again after a
  test reconnects.

## Upgrading

Nothing to change; a conftest that closed the connections itself or set `CONN_MAX_AGE` to
0 for the tests may drop it.
