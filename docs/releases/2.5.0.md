# bazis-test-utils 2.5.0

## Features

- **A pytest plugin.** The package registers the entry point `pytest11` `bazis`
  (`bazis_test_utils.plugin`), active in every test session where it is installed:
  - the triggers of `django-pgtrigger` are installed in the test database once it is set
    up (after `django_db_setup`, also when a conftest overrides it), if `pgtrigger` is in
    `INSTALLED_APPS`: the projects no longer need a `django_db_setup` of their own for
    them (one that installs them too keeps working);
  - `apply_declarations(using='default')` applies the declarations of the code of the
    installed Bazis packages, the roles of bazis-permit 2.9 (`roles.py`) and the workflows
    of bazis-statusy 2.9 (`workflow.py`), with the functions `migrate` calls, then forgets
    the cached permissions and content types; the fixture `bazis_declared` calls it. The
    migrated test database already has the declarations (`migrate`, also on a database
    kept by `--reuse-db`, and `flush` after a test with `transaction=True` apply them):
    the fixture is for a test that changes the declared rows itself. An older package
    without declarations is skipped.

  The plugin imports nothing of Django or Bazis before it is used.

## Tests

- The package has tests of its own (`tests/`, the plugin in pytester subprocesses with
  Django on SQLite), run by CI.
