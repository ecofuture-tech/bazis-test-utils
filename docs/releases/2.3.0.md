# bazis-test-utils 2.3.0

- `starlette.testclient` in Starlette 1.3+ uses `httpx2` and warns when only `httpx` is
  installed; `httpx2` is now a dependency (`httpx` stays for older Starlette releases).
- `get_api_client` passes `client=` to `TestClient`, which needs Starlette 0.44:
  the minimum versions are now `fastapi>=0.118` and `starlette>=0.44`. All dependencies
  received minimum versions (`django>=5.2`, `pytest>=8`, `pytest-django>=4.9`, ...).
- `requests`, `requests-toolbelt` and `requests-mock` are no longer dependencies: nothing
  in the package or in the Bazis test suites uses them. Projects that do must declare them.
- Optional arguments of the API client are annotated as `X | None`.
- CI: lint, import and API client smoke test on Python 3.12–3.14 and with the lowest
  allowed dependency versions, and a distribution build. Releases are made with the
  Release workflow (see `CLAUDE.md`).
