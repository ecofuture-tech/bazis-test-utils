# bazis-test-utils 2.4.0

## Tools and AI agents

- The package ships `AGENTS.md` (the test setup of a Bazis project, the API client, the
  sample models and factories) and `bazis_manifest.toml` for tools and AI agents (see
  `docs/agents.md` of Bazis). With Bazis 2.4 installed,
  `bazis.core.introspect.validate_manifest('bazis_test_utils')` verifies the manifest;
  the package itself still does not depend on `bazis`.
